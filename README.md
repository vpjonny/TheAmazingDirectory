## How to add a listing

1. Fork this repository.
2. Add **one line** for your product to the matching section of `README.md`, keeping the section in alphabetical order:

   ```markdown
   - **[Product name](https://example.com)** — One sentence on what it does and who it is for. `Tag` `Tag`
   ```

3. If no section fits, create a new `## Category` section (and add it to [Contents](#contents)).
4. Open a pull request titled `Add <Product name>`.

Full rules are in [CONTRIBUTING.md](CONTRIBUTING.md). In short:

- One product per pull request.
- The product must be live and publicly accessible; no pre-launch waitlists, no dead links.
- The description is factual, one sentence, no marketing superlatives ("best", "#1", "revolutionary"), no emoji other than a country flag tag.
- Link to the product's own homepage, without tracking or affiliate parameters.
- Makers may list their own products — say so in the pull request.
- No adult (18+/NSFW) products.
